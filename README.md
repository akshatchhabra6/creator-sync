# CreatorSync

// A Web-Based Platform to Streamline Influencer Marketing and Enable Transparent Collaboration Between Creators and Brands

---

//Overview

CreatorSync is a web-based platform developed to simplify and organize the collaboration process between content creators and brands. The platform provides a centralized environment where creators can showcase their profiles and portfolios, while brands can post campaigns, search creators, and manage collaborations efficiently.

The project aims to reduce communication gaps, improve transparency, and automate the workflow involved in influencer marketing.
